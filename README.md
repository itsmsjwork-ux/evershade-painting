# EverShade Painting Co.

Responsive static website starter for a painting contractor.

## Files
- index.html — website content
- styles.css — responsive styling
- script.js — mobile navigation and WhatsApp estimate form

## Before launch
1. Replace the sample WhatsApp number in script.js (910000000000) with your business number, country code included and digits only.
2. Update contact details and service area in index.html.
3. Replace the example portfolio photography with your own completed project photos.
4. Review all website copy and ensure it accurately describes your business. The portfolio currently uses sample photos and is not a verified record of completed work.

## Enable GitHub Pages
1. Open Settings → Pages in this repository.
2. Under Build and deployment, choose Deploy from a branch.
3. Select branch main and folder /(root), then Save.
4. Wait for the deployment to finish. The website URL should be https://itsmsjwork-ux.github.io/evershade-painting/.

This is a static website. The estimate form opens WhatsApp and does not save enquiries to a database. The form will not open WhatsApp until the real number is configured. External image and font URLs require an internet connection.
